Bem-vindo ao repositório dedicado às aulas de **Java** realizadas no **SENAI**. Este espaço foi criado com o objetivo de consolidar o conhecimento na linguagem, aprimorar a lógica de programação e documentar a resolução de problemas práticos propostos em sala de aula.

---

## 🎯 Objetivos do Repositório

* **Aprimoramento Técnico:** Dominar desde a sintaxe básica até conceitos avançados de Orientação a Objetos (POO).
* **Resolução de Problemas:** Desenvolver o raciocínio lógico através de desafios, algoritmos e projetos práticos.
* **Boas Práticas:** Aplicar conceitos de código limpo (*Clean Code*), organização de pacotes e padrões de projeto.
* **Portfólio:** Servir como um registro de evolução técnica para o mercado de trabalho.
